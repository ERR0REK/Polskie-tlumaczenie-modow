# Release notes — v1.0.0 (do wklejenia w GitHub Release)

---

**Pierwsze publiczne wydanie!** 🇵🇱

Jeden resource pack, który tłumaczy **272 mody** do Minecrafta **1.21.1** na język polski — Create i wszystkie ważniejsze addony, Mekanism, Immersive Engineering, Farmer's Delight, Biomes O' Plenty, JEI, Jade, FTB, Xaero's i wiele więcej.

## Co dostajesz

- **Kompletne tłumaczenia** — każdy klucz z `en_us.json` ma polski odpowiednik (weryfikacja klucz po kluczu, 0 braków)
- **Spójny słownik** — te same rzeczy nazywają się tak samo w każdym modzie
- **Klimat Create** — addony w konwencji polskiej społeczności Create
- **Przetłumaczone configi** — ustawienia Mekanism, Supplementaries, JEI i innych po polsku
- **Bezpieczne placeholdery** — `%s` na swoich miejscach, zero crashy i pustych tekstów

## Instalacja

1. Pobierz `Polskie-tlumaczenie-modow-1.0.0.zip` z sekcji **Assets** poniżej
2. Wrzuć do folderu `resourcepacks`
3. Włącz paczkę w menu gry — i tyle

Działa na Forge, NeoForge, Fabric i Quilt.

## Pełna lista modów

Znajdziesz ją w [README](https://github.com/ERR0REK/Polskie-tlumaczenie-modow#przetłumaczone-mody) oraz w [CHANGELOG.md](https://github.com/ERR0REK/Polskie-tlumaczenie-modow/blob/main/CHANGELOG.md).

## Znalazłeś błąd?

Literówka, niezgrabne tłumaczenie albo świeży klucz po aktualizacji moda? [Otwórz issue](https://github.com/ERR0REK/Polskie-tlumaczenie-modow/issues) — poprawki wchodzą szybko.
