# Polish Language Pack for Mods

**Complete Polish translations for 260+ Minecraft mods - one resource pack, zero leftovers.**

Tired of half of your modded UI switching back to English? This pack adds full Polish (`pl_pl`) translations for a huge collection of mods covering technology, magic, storage, food, world generation, decoration and quality-of-life - all in one drop-in resource pack. Wrzucasz, włączasz, grasz.

---

## ✨ Features

- **260+ mods covered** - every localization key shipped by each mod's `en_us.json` has a Polish counterpart, verified key-by-key (not "eyeballed").
- **Consistent terminology** - machine names, tooltips, config screens, JEI categories and advancements follow one unified glossary across the whole pack (e.g. *Nadajnik wyświetlania* for Display Link, *Łącze Towarowe* for Cargo Link).
- **Create-flavored style** - Create and its addons are translated in the tone of the Polish Create community translations, so tutorials and videos keep making sense.
- **Placeholder-safe** - all `%s` / `%1$s` placeholders are preserved 1:1, so nothing crashes or renders empty in-game.
- **Config screens included** - settings menus (Mekanism, Supplementaries, JEI and many more) are fully translated, not just block names.

## 📦 Requirements

- **Minecraft:** 1.21.1
- **Loader:** any (Forge, NeoForge, Fabric, Quilt) - it's a plain resource pack
- **Installation:** drop the zip into your `resourcepacks` folder and enable it. That's it - no configuration needed.
- **Modpacks:** you are welcome to include this pack in your own modpacks, private or public. No permission needed - a mention is always appreciated though.

## 🔤 Translation style

- **Vanilla-aligned** - mod content follows the official Polish Minecraft terminology where one exists (*Netheryt*, *Fortuna*, *Zaklęcie ostateczne*...).
- **Community-aligned** - Create terms match the widely used Polish Create community glossary so tutorials and videos stay consistent.
- **Readable, not robotic** - in-game names use the forms players actually say (*metrówka*, not *taśma miernicza*).

## 🐛 Found an issue?

Missing key, awkward phrasing or a typo? Open an issue on GitHub - feedback in both Polish and English is welcome and fixes land fast.

## 📄 About these translations

The translations in this pack were prepared with the help of AI language tools and then reviewed, corrected and unified manually across multiple quality passes (terminology, grammar and placeholder checks). The pack itself is maintained by hand.

## 📃 Notes

This pack contains only localization files (`.json` language strings). All game content, names and trademarks belong to their respective mod authors. Translations are provided as-is for personal and public modpack use.
